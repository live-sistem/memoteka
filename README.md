# МЕМОТЕКА 🎭

Небольшой статический сайт-«музей мемов»: чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск

Просто открой `index.html` в браузере — или подними локальный сервер:

```powershell
python -m http.server 8000
# затем http://localhost:8000
```

## Что внутри

- 11 классических мем-шаблонов в `assets/`
- поиск по названию, описанию и тегам
- фильтр по тегам и сортировка (порядок / лайки / А–Я)
- **общие лайки** через [Abacus](https://abacus.jasoncameron.dev) — один посетитель = один лайк, число видят все
- лайтбокс с деталями мема
- кнопка «Случайный мем»
- горячие клавиши: `/` — поиск, `R` — случайный, `Esc` — закрыть
- адаптивная вёрстка, поддержка `prefers-reduced-motion`

## Структура

```
MemeSite/
├── index.html
├── styles.css
├── app.js
├── assets/        # картинки мемов (imgflip)
└── README.md
```

## Как добавить мем

Положи картинку в `assets/` и добавь объект в массив `MEMES` в `app.js`:

```js
{ id: "my-meme", file: "assets/my-meme.jpg", title: "Название", caption: "Подпись", tags: ["код"] }
```

## Источник шаблонов

Картинки — публичные шаблоны с [imgflip.com](https://imgflip.com). Используй их для личных проектов.
